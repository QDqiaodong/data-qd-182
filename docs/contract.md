# 织机样布组织 v1

使用者为样布技术员。shafts=1..16；tie_up的唯一踏板id映射到无重复的shaft编号（1起，可空），最多32踏板。warp为1..128个经纱端，每端有shaft和yarn；picks为1..128纬，每纬选择无重复已知踏板和yarn。织机模型为升综式：同纬踏板的shaft做并集，属于升起综框的经端在纬纱上方，输出drawdown_warp_above的1，否则0。支持空踏板（全落下），这是有效但可能不可织的组织，不把质量问题当解析失败。

一个repeat在经纬两个方向无限平铺，warp沿各列连续1为经浮长，weft沿各行连续0为纬浮长。必须跨repeat首尾检测循环连续段；一整列1或一整行0表示相应方向在无限平铺下无交织约束，max_crossings=null、unbounded=true。其他max为整数；超过float_limit或unbounded生成质量违规，按方向和0起索引列出。该无限重复结构审查与本次有限订单repeat数独立，不能以只生产一重复隐去无界结构。质量违规仍退出0并明确输出float_violations。

repeat_x/repeat_y各1..1000，warp_spacing_mm/pick_spacing_mm为1..100整数。成布宽=总经端数×经间距，长=总纬数×纬间距；这是本仓名义格距规则，不是纱线直径模型。takeup_permille为0..1000，每根经/每纬的材料长度=ceil(布方向长度×(1000+takeup)/1000)，经纱另加warp_waste_mm；按同方向yarn汇总。纱线用量与实际经纬组织身份一致，但不按逐个交织点模拟卷曲；系数由用户指定，不预测真实缩水/张力。

所有字段严格检查、布尔值不当整数。没有织机通信、库存扣料、色牢度、物理张力或断经监测。先完整计算组织、风险、用量后原子新建单个JSON，目标已存在或输入非法退出2且旧目标保持。
